# osm-land-polygons
This is a simple Python project that extracts land or island polygons from OpenStreetMap for autonomous ship navigation purposes.


## Installation

You can set up the environment using either **conda** or **venv**.

### Option 1: Using conda (preferred)

```bash
# Create and activate a conda environment
conda create -n osm-env python=3.10 -y
conda activate osm-env
```

### Option 2: Using a virtual environment
```bash
# Create and activate a venv
python -m venv .venv
source .venv/bin/activate    # On Linux / macOS
.venv\Scripts\activate       # On Windows
```
### Finally, install dependencies
```
pip install -e.
```
